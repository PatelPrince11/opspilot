# search-api-01 slow: GC pauses on search-cluster-03 (sev4)

8 December 2025, 01:00 to 01:45 UTC. Runbook RB-003. From 01:00 searches through search-api-01 came back slower than usual. The hot-threads output for search-cluster-03 showed it busy in garbage collection and not in search work, and that was taken as the cause: long GC pauses on that node were holding up the calls search-api-01 sent to it. RB-003 routes GC trouble on a cluster node to team-platform, so that is where it went, and what that team did is not described here; this account records no error codes, only slow responses. No query was cancelled and I changed no cluster settings. By 01:45 search latency was back to normal.

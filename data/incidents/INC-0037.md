# orders-api-02 and -03: busy event loop, edge 504 (sev3)

Tuesday 29 April 2025, 21:55 to 23:00 UTC, 65 minutes. Runbooks RB-002 and RB-004. From 21:55 the edge answered some orders-api requests with `504`; the pods behind them were orders-api-02 and orders-api-03, where CPU-bound work on the event loop held requests until the gateway gave up.

Which function or request type consumed the CPU was not identified, and no change to the service is recorded. RB-002 (CPU pressure on a pod) and RB-004 (orders-api trouble) are the runbooks linked to it. Requests routed to the other orders-api instance are not described. The on-call handled the incident, and by 23:00 the edge had stopped returning `504` for orders-api.
